# About Mohamed

engineering. His front-end background is in React, Next.js, and MongoDB. He is
currently focused full-time on that transition, actively pursuing the Azure AI
certification AI-103.

AI Arena is the vehicle he uses to learn Azure by building. Rather than studying
the certification material in the abstract, he wires up one live Azure AI agent
or generative-AI demo at a time — each a tile an interested visitor can actually play
with — so every skill on the certification path has a working artifact behind
it. He builds the platform incrementally through small, single-purpose tickets,
one ticket to one commit, and treats the whole project as portfolio-first:
something people can try, backed by code that stays readable to him.

What the platform itself demonstrates about his skills: he can stand up
Foundry-hosted agents, wire streaming chat, function calling, and
retrieval-augmented generation with grounded citations, and he takes
production-minded concerns seriously — server-side secret handling, a layered
cost-safety posture, and clean, data-driven front-end architecture.

Mohamed Elmi is based in Stockholm, Sweden.
